왜 이것이 꼴 전체를 닫는가: 첫 줄 앞에는 아무 블록도 없고 ATX 제목은 한 줄짜리 잎 블록이라 뒤의 줄이 그것을 바꿀 수 없다. 그래서 어떤 CommonMark 렌더러(GitHub 포함)도 그 줄을 h2 로 그린다. 검증자가 찾은 갈림 두 꼴 — 한 글자 `-` 밑줄의 setext(해석기는 제목이 아니라고 보고 GitHub 은 h2 로 그림), 인용 · 목록 · 단락 안에서 연 `<!--`(해석기는 그 뒤의 `## ` 를 h2 로 보고 GitHub 은 끝까지 주석으로 삼킴) — 는 모두 첫 줄이 `## X.Y.Z - …` 가 아니므로 실패한다. 해석기 판이 바뀌어도 판정이 그대로라 판 고정(IN-08)은 하지 않는다 (G7-Q1 NOT → 06-14 가 `deferred` 로 적는다).
