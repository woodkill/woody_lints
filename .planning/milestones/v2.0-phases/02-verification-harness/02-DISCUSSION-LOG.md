## pubspec.lock 커밋 (D11)

찾아본 것: dart.dev 는 앱은 `pubspec.lock` 을 커밋하고 라이브러리는 커밋하지 말라고 안내한다. GitHub 은 공개 저장소에서 60일 동안 활동이 없으면 예약 workflow 를 자동으로 끈다.

### lock 커밋 여부

| Option | Description | Selected |
|--------|-------------|----------|
| 커밋한다 (권고) | 내 컴퓨터와 GitHub 이 같은 버전으로 점검한다. 기반 세트 새 버전은 일부러 올릴 때 들어오고 그 영향이 정답지 diff 로 보인다. `.gitignore` 에 예외 한 줄을 더한다 | ✓ |
| 커밋하지 않는다 | 점검할 때마다 최신 호환 버전을 새로 받는다. 기반 세트 변화가 바로 드러나지만 내 변경과 무관한 실패가 섞이고 내 컴퓨터와 GitHub 의 결과가 다를 수 있다 | |

**User's choice:** 커밋한다 (권고)
**Notes:** 설명한 전제 — lock 이 묶는 것(기반 세트, `example/` 의 Riverpod 패키지)과 못 묶는 것(`riverpod_lint` plugin). 기반 세트는 규칙을 바꿀 때 major 를 올리고 선언이 `^6.0.0` 이라 "커밋하지 않는다"의 조기 경보가 울릴 일은 많지 않다.

### 저장소 변경 없이 깨지는 경우를 알아채는 방법

| Option | Description | Selected |
|--------|-------------|----------|
| 수동 실행 버튼 추가 (권고) | push·PR 점검에 더해 GitHub 화면에서 "지금 돌려 보기"를 누를 수 있게 한다. 버튼은 릴리스 뒤 `main` 에 들어간 다음부터 보인다 | ✓ |
| push·PR 때만 | 요구사항 그대로 두고 아무것도 더하지 않는다 | |
| 주 1회 예약 점검 | 매주 자동으로 돌고 실패하면 메일이 온다. 60일 동안 저장소 활동이 없으면 예약이 꺼진다 | |

**User's choice:** 수동 실행 버튼 추가 (권고)
**Notes:** 어느 쪽이든 점검 화면에 실제로 쓰인 버전(SDK, 기반 세트, plugin)을 찍겠다고 밝혔다.

## GitHub 에 올리는 방식

찾아본 것: push 와 PR 을 둘 다 걸면 점검이 두 번 돌고, `concurrency` 로 겹치는 실행을 취소하는 것이 보통이다. `.planning/` 을 공개 저장소에 둘지에 대한 정해진 관행은 찾지 못했다.

질문 전에 브랜치를 올리면 공개될 내용을 저장소에서 직접 확인해 표로 보였다: `.planning/` 38개 파일, 다른 프로젝트 이름 18개 파일, 로컬 절대 경로 9개 파일, 커밋 메시지 51개의 Claude 세션 주소, 비밀번호·토큰 없음, 이메일은 이미 공개된 커밋 작성자 정보와 같은 주소.

### `.planning/` 의 공개 범위

| Option | Description | Selected |
|--------|-------------|----------|
| 그대로 올린다 (권고) | 작업 브랜치를 `.planning/` 과 함께 올린다. 절차가 단순하고 계획 문서가 GitHub 에 백업된다 | ✓ |
| `.planning/` 을 뺀 사본을 올린다 | 계획 문서 커밋을 걸러 낸 사본 브랜치를 만들어 그것만 올린다. 올릴 때마다 사본을 다시 만들어야 하고 릴리스 때도 걸러서 합쳐야 한다 | |

**User's choice:** 그대로 올린다 (권고)
**Notes:** 한 번 올린 것은 지워도 흔적이 남을 수 있다는 점, Claude 세션 주소가 본인 계정으로만 열리는지는 확인하지 못했다는 점을 밝혔다.

### 명령의 형태

| Option | Description | Selected |
|--------|-------------|----------|
| Dart 스크립트 (권고) | `fvm dart run tool/verify.dart` 한 줄. Flutter 만 있으면 돌고 추가 패키지를 쓰지 않는다. `tool/` 에 `.dart` 파일이 생기지만 `lib/` 와 무관하다 | ✓ |
