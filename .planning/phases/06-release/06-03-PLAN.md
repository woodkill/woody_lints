**1. 인자.** `<ref>` 하나(커밋 번호 · 브랜치 · tag)와 선택 `--keep`. 인자가 없거나 ref 가 둘 이상이거나 모르는 옵션(`--` 로 시작하는 다른 것)이 있거나 ref 가 `-` 로 시작하면(git 인자 주입 방지 — V5) stderr 에 `사용법: fvm dart run tool/smoke.dart <ref> [--keep]` 를 찍고 `quit(64)`.

**2.
